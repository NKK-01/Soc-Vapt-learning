# Cyvero Cybersecurity With AI Mastery

## Overview

This repository contains a comprehensive curriculum for mastering cybersecurity fundamentals, vulnerability assessment, penetration testing (VAPT), Security Operations Center (SOC) operations, and the integration of AI in cybersecurity.

The material is structured into four core modules, covering everything from networking basics to advanced SIEM tools, ethical hacking techniques, and AI-driven threat detection.

---

## Modules

### Module 0.1: Foundations of Networking

- OSI & TCP/IP models
- IPv4/IPv6 addressing, public vs. private IPs, IP classes
- Subnetting, CIDR, subnet masks
- Core protocols: DHCP, DNS, ARP, ICMP
- Static & dynamic routing, RIP
- Access Control Lists (ACL)
- Cryptography (symmetric/asymmetric encryption, hashing, PKI)
- VPN technologies (IPsec, GRE, L2TP, SSL VPN)
- Wireless security (WPA2/WPA3, attacks & mitigation)

### Module 0.2: Pre-Security Fundamentals

- Linux basics, file hierarchy, terminal commands
- VirtualBox & VMware setup
- User & permission management (`chmod`, `chown`)
- Linux networking & monitoring logs
- Windows fundamentals: NTFS, Registry, UAC, Defender
- Windows Event Logs & critical Event IDs
- HTTP/HTTPS, TLS/SSL, session management
- TCP/UDP, three-way handshake, common ports
- Active Directory: domains, Kerberos, Group Policy
- AI fundamentals: supervised/unsupervised learning, malware/phishing detection, VirusTotal

### Module 0.3: Vulnerability Assessment and Penetration Testing (VAPT)

- Web app security: LFI/RFI, XSS, command injection, SQLi
- OWASP Top 10 (2025): Broken Access Control, IDOR, SSRF, etc.
- Nmap scanning (host discovery, OS fingerprinting, NSE)
- Burp Suite (Proxy, Repeater, Intruder)
- CVSS & CVE, Metasploit framework
- Shell techniques: bind/reverse/web shells, Netcat, Socat, msfvenom
- Privilege escalation (Linux: linPEAS, sudo, SUID; Windows: WinPEAS, DLL hijacking)
- AI-driven threats (Evil GPT, AI phishing, automated exploitation)

### Module 0.4: Security Operations Center (SOC)

- SOC roles (L1/L2 analysts), monitoring, incident response
- Cyber Kill Chain & MITRE ATT&CK framework
- Log analysis (Windows Event IDs, Linux logs)
- SIEM tools: Splunk (SPL queries, dashboards), ELK Stack, Wazuh
- Network monitoring with Snort (IDS/IPS) & Wireshark
- Incident handling playbooks (phishing, malware, brute force, insider threat)
- Threat intelligence, IOC analysis, MITRE mapping
- Cloud security: IaaS/PaaS/SaaS, IAM, cloud incident response
